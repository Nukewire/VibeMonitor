2 · Summaries — optional

AI one-line "what is this session working on" labels via OpenRouter. The latest prompt text is sent to a third party, so it is off by default. Skip this to leave summaries disabled.

3 · Phone push — optional

Get a phone push when a session starts waiting on you. Leave the provider on "None" (or skip) to disable.

4 · Home Assistant — optional

If set, the bridge POSTs a webhook the moment a session needs you (and when it clears). Create a webhook automation in Home Assistant, then paste its URL here. You can skip this — we still show you the paste-ready YAML at the end.

5 · Finish

Write config.toml and (if Claude is enabled) install the Claude Code hooks.
